## 📋 Project Description

An Object-Oriented Java application for a beauty store that allows customers to:
- Browse products (best sellers & full catalog)
- Add/remove items from a shopping cart
- Choose from three shipping methods
- Complete checkout with automatic stock updates
- Generate invoices

## ✨ Features

- Product Management with stock & weight
- Shopping Cart with stock validation
- Three Shipping Options:
  - 🚚 Ground Shipping (max 7 KG) — 5% extra
  - ✈️ Air Shipping (max 50 KG) — 8% extra
  - ⚡ Express Shipping (any weight) — 15%/25% extra
- Weight-based shipping validation
- Automatic stock update after purchase
- Invoice generation

## 🛠️ Technologies

- OOP: Inheritance, Polymorphism, Encapsulation
- Exception Handling
